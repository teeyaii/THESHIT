# DOCX coverage v2
Read-only exact span auditing across main document, nested tables, headers, footers, footnotes and endnotes. Each paragraph has XML part, index, text, explicit RGB shading per Unicode code point and table depth. Hyperlink runs are included. Approved spans are tied to the exact DOCX SHA-256.
Named Word highlight, theme/pattern shading, fields, revisions and non-text structures are flagged rather than silently counted as matching. Style-based or inherited shading is not resolved. Missing, wrong, unexpected and unresolved positions are reported; any semantic completeness, printed layout and source-color correctness remain independent human tasks. Text boxes and complex Word structures need additional visual verification. No modification of source and no private documents in public CI. This is not a full semantic Evidence Atlas acceptance or Microsoft Word visual QA.

# Computed report engine
Build a new synthetic-only report bundle from statistical_engine.analyze results. No generated empirical narrative.
Outputs: computed canonical JSON, DOCX, Excel, Markdown. Every numeric table is derived from the same JSON; SHA-256 binds the source. Excel text cells are forced to string type to avoid formula execution. Word header/footer and visible title are labeled synthetic.
Reopen Word/Excel and compare all cells and labels to source JSON. The structural QA result is not a cryptographic signature or proof the input was generated by an approved study. No PDF/Word visual acceptance, Thai font layout or thesis template yet.
Public CI only uses generated fixtures. Do not commit generated outputs. Future reporting: approved templates, verified citations, independent narrative review, Windows Word PDF finalization.

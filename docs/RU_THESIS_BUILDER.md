# RU MBA thesis builder — synthetic structure only
Uses ru_mba_campus_2569_working. Chapter titles 20 pt; body Browallia New 16 pt and first-line 0.5 inch. Named styles assign Thai/Latin/complex script slots; provisional single spacing, title alignment, subheadings and other preview choices are NOT verified official 2569 requirements. A uniform numbered-page top margin is used for the fixture, not a final rule for all page roles.
Builds a new DOCX and JSON manifest with cover placeholder, Thai/English abstract placeholders, Word TOC field (not updated), chapters 1–5 in order, computed synthetic chapter 4 numeric prose and a table, pending chapter 5 discussion, bibliography and appendix placeholders. No fictional references, actual questionnaire, participants, real study content or approval. All output labeled synthetic, not for academic submission.
Run python ru_thesis_builder.py demo --output outputs/SYNTHETIC_RU then python ru_thesis_builder.py verify --output outputs/SYNTHETIC_RU. Verifies file hash, paragraph content/style, table cells, chapter order, body/chapter font declarations and TOC field presence. Dedicated CI generates a downloadable structure artifact only; no actual font installed or rendered Word acceptance. Real manuscript assembly preserving existing fields, highlights, tables, figures and citations is a separate implementation. Template approval, field update, page role/numbering, all page visual inspection in Microsoft Word Desktop and academic review remain mandatory. Do not upload private manuscript or font files.

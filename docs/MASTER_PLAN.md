# THESHIT master plan
Public software repository; no private research files or participant data.
1. Core statistics demo: deterministic, synthetic-only.
2. Protocol and codebook: versioned draft schema, data checks, source verification gate.
3. Evidence: citation/evidence index schema, traceability, no fabricated evidence.
4. Simulation: neutral fixtures and explicit synthetic labels, no p-value targeting.
5. Statistics: approved scoring, missing-data handling, diagnostics, OLS and HC3, SPSS cross-check.
6. Reporting: reproducible tables and chapter templates; no unsupported empirical claims.
7. Dashboard: evaluate secure private data architecture, authentication and hosting before real intake.
8. Independent QA: code tests, methodology and evidence review, human release.
## Roles
ChatGPT: architecture and integration; Codex: implementation and tests; Claude: independent methodology/document review; owner: approval.
## Release gates
CI success is software validation only. Real analysis requires verified current questionnaire, locked codebook, approved protocol, applicable ethics and consent, authorized de-identified input, private storage and predeclared analysis. No academic submission from demo results.
## Next handoff

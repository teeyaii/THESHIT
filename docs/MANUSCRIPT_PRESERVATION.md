# Manuscript preservation — conservative gate
Compare exact OPC part bytes across two existing DOCX copies; report additions/removals/changes, without outputting document text. Does not interpret semantic differences or certify visual parity.
Synthetic append prototype only: compatible packages must have identical non-main parts and terminal section properties. Append plain paragraphs/tables without rebuilding run XML; verify canonical blocks, original source hashes and unchanged ancillary parts. Reject cross-package hyperlinks, drawings, comments, fields, lists, bookmarks, revisions, footnotes and other complex links rather than silently losing them. No automatic style normalization or real manuscript assembly. Complex assembly requires explicit relationship/ID remapping and independent Word tests. All private documents stay off public GitHub. Never claim a complete merger for an existing real thesis on the basis of these fixtures.

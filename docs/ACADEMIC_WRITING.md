# Academic Writing Engine — deterministic first
Synthetic-only Thai narrative from statistical_engine.analyze. No AI service, prompt or real-data ingestion.
- Generates methods, cases, model, every predictor's classical p and HC3 p/SE/CI, and limitations from computed JSON. No automatic hypothesis acceptance, significance claim or causal interpretation.
- Each numerical fact has an immutable source report SHA-256, JSON pointer, value and rendered text. Draft verification regenerates the exact output, detects altered text or facts and retains negative/null outcomes. Method wording describes the tested implementation, not a real study protocol.
- Plain text and JSON export with explicit synthetic label and DRAFT_REVIEW_REQUIRED. Human review required.
- Discussion and literature synthesis stay blocked until independently reviewed source claims and an explicit citation/interpretation policy are available. No invented citation, approval, statistic or source. No empirical thesis chapter or final academic acceptance.
- Tests use fixed generated data, include negative coefficient, every numerical fact traceability and tamper detection.

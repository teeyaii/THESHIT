# THESHIT — engineering rules
- This repository contains generic software only. Never commit participant data, identifying metadata, private study documents, credentials, or unpublished evidence.
- Keep synthetic test fixtures explicitly labelled SYNTHETIC — NOT RESEARCH EVIDENCE. Never present simulated data or statistics as observed research results.
- Do not tune or select datasets to obtain significant hypotheses. Preserve null and negative findings.
- Real-data intake is disabled in v0.1; require an approved protocol, locked codebook, authorized de-identified input and provenance checks before enabling it in a private environment.
- Codex: implementation, automated tests, reproducibility. Claude: independent methodological and document review. Human: approval before merge and release.
- Never fabricate references, screenshots, ethics approvals, IOC, reliability, or participant counts. Report missing evidence as missing.
- All changes via reviewable pull requests; report tests actually executed and limitations.
